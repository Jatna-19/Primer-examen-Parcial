Integración Continua
y Despliegue Automático

En esta práctica aprenderemos cómo crear una página web, guardar el código en GitHub y automatizar su publicación utilizando GitHub Actions y Surge.sh.

Conocer el proyecto ↓

Tecnologías utilizadas

Para desarrollar esta práctica utilizamos herramientas que permiten crear, almacenar y publicar páginas web.

🌐

HTML y CSS

HTML organiza los textos y elementos de la página, mientras que CSS permite personalizar el diseño, los colores y la distribución del contenido.

🐙

GitHub

Permite guardar el código del proyecto en un repositorio y mantener un historial de los cambios realizados durante el desarrollo.

⚙️

GitHub Actions

Automatiza tareas cuando se envían cambios al repositorio, como ejecutar los pasos necesarios para publicar una nueva versión de la página.

🚀

Surge.sh

Es un servicio que permite alojar páginas web estáticas y compartirlas mediante una dirección pública de Internet.

Pasos de la integración continua

Este es el proceso que seguimos para automatizar la publicación de nuestra página web.

1

Crear la página web

Diseñamos el archivo index.html utilizando Visual Studio Code, HTML y CSS.

2

Crear el repositorio en GitHub

Subimos los archivos del proyecto para mantener el código disponible en un repositorio remoto.

3

Configurar GitHub Actions

Creamos un archivo YAML que define las instrucciones que se ejecutarán cuando enviemos cambios a la rama principal del repositorio.

4

Publicar con Surge.sh

Configuramos el despliegue para enviar los archivos a Surge de manera automática, utilizando un secreto de GitHub para proteger el token de acceso.

¡Nuestro proyecto en Internet!

La integración continua nos ayuda a simplificar las actualizaciones de una página web y a comprender cómo se pueden automatizar tareas del desarrollo.
